A lossless PNG re-encoder for 1280×720 RGBA screenshots: colour-type reduction, adaptive per-scanline filtering and an optimal-parse DEFLATE encoder written from the DEFLATE spec, that writes the smallest valid PNG for each screenshot.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
